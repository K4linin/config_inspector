## Описание

Config Inspector — клон интерфейса системы EFROS, предназначенный для демонстрации возможностей контроля целостности устройств:

- **Мониторинг** — графики нарушений, состояния устройств, прогресс проверок безопасности
- **Устройства** — дерево устройств по группам, 4 вкладки (Статус / Отчёты / События / Архив), правая панель с настройкой и CVE-уязвимостями
- **События** — журнал системных событий с фильтрацией по устройству, типу и времени
- **Настройки** — карточки разделов с диалогами: Расписание, Сканирование сети, Карта сети, Отчёты

Встроенный **симулятор** в реальном времени генерирует нарушения целостности, события подключения/отключения и уязвимости — все страницы обновляются автоматически.

## Быстрый старт — Windows

### 1. Установка Python

Скачай Python 3.11+ с [python.org](https://www.python.org/downloads/).  
При установке **обязательно** отметь «Add Python to PATH».

Проверь:
```cmd
python --version
```

### 2. Клонирование / распаковка проекта

```cmd
git clone <ссылка-на-репозиторий>
cd config_inspector
```

Или просто распакуй ZIP-архив и перейди в папку `config_inspector`.

### 3. Создание виртуального окружения (рекомендуется)

```cmd
python -m venv .venv
.venv\Scripts\activate
```

После активации в начале строки появится `(.venv)`.

### 4. Установка зависимостей

```cmd
pip install -r requirements.txt
```

Ожидаемый результат — установка пакетов `PyQt6`, `PyQt6-Qt6`, `PyQt6-sip`, `PyQt6-QtSvg`.

### 5. Запуск приложения

```cmd
python main.py
```

Откроется окно входа. Используй учётные данные из раздела [Учётные данные](#учётные-данные-демо).

## Быстрый старт — Linux / macOS

### Ubuntu / Debian

```bash
# Системные библиотеки Qt6
sudo apt-get update
sudo apt-get install -y libgl1-mesa-glx libglib2.0-0 \
    libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0 \
    libxcb-xinerama0 libxkbcommon-x11-0 fonts-liberation

# Python и venv
sudo apt-get install -y python3.11 python3.11-venv python3-pip
python3.11 -m venv .venv
source .venv/bin/activate

# Зависимости
pip install -r requirements.txt

# Запуск
python main.py
```

### macOS (Homebrew)

```bash
brew install python@3.11
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

> **Примечание macOS:** если появляется ошибка «This application requires a Qt platform plugin», выполни:
> ```bash
> export QT_QPA_PLATFORM=cocoa
> python main.py
> ```

## Запуск через Docker

Docker позволяет запустить приложение без установки Python и Qt на хосте.  
GUI выводится через X11-forwarding (Linux) или встроенный VNC-сервер.

### Вариант A — Linux с X11 (самый простой)

```bash
# Разрешить доступ к X-серверу
xhost +local:docker

# Сборка образа
docker build -t config-inspector .

# Запуск с проброской дисплея
docker run --rm \
    -e DISPLAY=$DISPLAY \
    -v /tmp/.X11-unix:/tmp/.X11-unix \
    config-inspector
```

### Вариант B — Headless / CI (без дисплея)

```bash
docker build -t config-inspector .

# Запуск через виртуальный дисплей Xvfb (не открывает окно)
docker run --rm config-inspector \
    xvfb-run -a --server-args="-screen 0 1280x800x24" python main.py
```

### Вариант C — Windows / macOS через браузер (VNC)

```bash
docker compose up --build
```

После запуска открой в браузере:

```
http://localhost:6080
```

Пароль VNC: не требуется (пустой).

Остановить:
```bash
docker compose down
```

### Пересборка после изменений кода

```bash
docker build --no-cache -t config-inspector .
```

## Сборка в EXE (Windows)

Файл `build_exe.bat` автоматически устанавливает PyInstaller и собирает `dist\ConfigInspector.exe`.

```cmd
build_exe.bat
```

Готовый EXE будет в:
```
dist\ConfigInspector.exe
```

> **Важно:** EXE включает Python-рантайм (~40 МБ). Запускается без установки Python на целевой машине.  
> Для включения иконок SVG добавь в `build_exe.bat` флаг `--add-data "icons;icons"`.

## Страницы и функции

### Мониторинг

- Сводные карточки: всего устройств, нарушений, проверок безопасности
- Линейный график нарушений в реальном времени
- Круговая диаграмма статусов устройств
- Список последних событий и нарушений

### Устройства

| Область | Что умеет |
|---------|-----------|
| Тулбар | Добавить группу/устройство, Изменить, Удалить, Копировать, Обновить, Фильтр — все кнопки открывают диалоги |
| Дерево | Группировка по папкам (windows / AD / net), живые иконки статусов |
| Поиск | Фильтрация дерева по тексту в реальном времени |
| Вкладка Статус | Список нарушений с возможностью принять, последние события, расписания |
| Вкладка Отчёты | Группировка по типу, фильтр «Только нарушения» |
| Вкладка События | Фильтр по типу, поиск |
| Вкладка Архив | Экспорт, фильтр по периоду |
| Правая панель | Действия, Сведения, **Настройка** (конфиг агента), **Уязвимости** (CVE) |

### События

- Журнал с колонками: Устройство / Время / Тип / Сообщение
- Боковой фильтр: по времени (с/по), по устройствам, по типу
- Детальная панель внизу с расшифровкой результата
- Кнопка «Обновить» — подгружает live-события из симулятора

### Настройки

| Раздел | Действие при клике |
|--------|--------------------|
| Устройства | Диалог «Сканирование сети» с прогрессом и таблицей устройств |
| Карта (ссылка в Устройства) | Интерактивная карта сети (QPainter, клик по узлу) |
| Отчёты | Диалог управления отчётами + форма создания |
| Расписания | Диалог расписания задач с CRUD и кнопкой «Выполнить сейчас» |
| Остальные | Сообщение демо-режима |

## Симулятор

Симулятор запускается кнопкой **▶ Симуляция** в шапке приложения.

| Скорость | Интервал тика |
|----------|--------------|
| 1×       | ~2.5 сек     |
| 2×       | ~1.25 сек    |
| 5×       | ~500 мс      |

На каждом тике случайно генерируется одно из событий:

| Событие | Вероятность | Эффект |
|---------|-------------|--------|
| Загрузка отчёта | 35% | Счётчик отчётов +1 |
| Нарушение целостности | 12% | Статус → Нарушение, добавляется в список |
| Подключение | 20% | Статус → В норме |
| Потеря связи | 8% | Статус → Нет связи |
| Уязвимость | 8% | Счётчик CVE +1 |
| Событие безопасности | 4% | Прогресс проверок |
| Устранение нарушения | 13% | Снятие нарушения |

Все страницы обновляются автоматически через сигнал `DataStore.changed`.

## Иконки для раздела Настройки

Если хочешь добавить свои иконки в карточки раздела «Настройки»:

1. Подготовь SVG-файлы размером **28×28 px**, белые символы на прозрачном фоне
2. Положи в папку `icons/` рядом с `main.py`
3. Назови файлы строго по номерам:

| Файл | Раздел |
|------|--------|
| `1.svg` | Обработка событий |
| `2.svg` | Профили |
| `3.svg` | Устройства |
| `4.svg` | Отчёты |
| `5.svg` | Проверки |
| `6.svg` | Расписания |
| `7.svg` | Модули |
| `8.svg` | Пользователи |
| `9.svg` | База данных |
| `10.svg` | Лицензии |

Если файл отсутствует — автоматически отображается нарисованный символ на цветном фоне.

## Известные ограничения

- **Данные не сохраняются** между перезапусками — всё хранится в памяти (DataStore)
- **Добавление устройств** через диалог сохраняется только до закрытия приложения
- **Docker на Windows/macOS** требует дополнительного X-сервера (VcXsrv / XQuartz) или используй Вариант C с VNC
- **PyQt6-QtSvg** нужен только для загрузки SVG-иконок; если пакет не установлен — используются fallback-символы
- Тестировалось на Python 3.11 – 3.14, PyQt6 6.6 – 6.11
