Иконки для страницы «Настройки»
================================

Поместите SVG-файлы с именами 1.svg, 2.svg, ... в эту папку.

Соответствие номеров разделам:
  1.svg  — Обработка событий
  2.svg  — Профили
  3.svg  — Устройства
  4.svg  — Отчёты
  5.svg  — Проверки
  6.svg  — Расписания
  7.svg  — Модули
  8.svg  — Пользователи
  9.svg  — База данных
  10.svg — Лицензии

Рекомендуемый размер: 28×28 px, белые символы на прозрачном фоне.
Цвет фона задаётся кодом (зелёный / синий) — не нужно включать его в SVG.
